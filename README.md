# Jogo da Forca P2P 

Implementação de um cliente P2P (Peer-to-Peer) do clássico **Jogo da Forca**, desenvolvido como trabalho prático para a disciplina de Redes de Computadores. 

O sistema opera de forma descentralizada, utilizando um servidor Rendezvous apenas para registro e descoberta inicial de peers, enquanto toda a comunicação de lobby e o andamento das partidas ocorrem diretamente entre os nós por meio de conexões TCP persistentes.
